                                                                   Medicinal Plant Detection (Flask App)
This project is a Flask-based web application that uses deep learning to identify medicinal plants from leaf images. 
By uploading a plant image, users can get accurate predictions of the plant name and its medicinal properties.
The model is trained using a Convolutional Neural Network (CNN) built with TensorFlow and Keras. This application helps in promoting the use of herbal remedies and supports quick identification of useful medicinal plants through AI.
